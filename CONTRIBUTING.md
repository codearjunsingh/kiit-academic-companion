# 🤝 Contributing to StudyOS

Thank you for your interest in contributing to **StudyOS**!

## 📜 Architectural Guidelines

1. **Personal First, Open Source Ready**: StudyOS is built specifically to maximize Arjun's learning trajectory while remaining modular for open-source adoption.
2. **Prerequisite-Driven Knowledge**: All new topics added to the Knowledge Graph must include prerequisites, real-world applications, common mistakes, and interview questions.
3. **TypeScript Strictness**: Code must compile cleanly with 0 type errors (`npx tsc`).
4. **TailwindCSS & Glassmorphism**: Use curated dark modes, HSL tailored gradients, and sleek micro-animations.

---

## 🛠️ Local Setup

```bash
git clone https://github.com/codearjunsingh/study-os.git
cd study-os
npm install
npm run dev
```
